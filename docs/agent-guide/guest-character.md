# A singing guest in a HUD video
Use `music-video-hud-guest` for an uploaded duet song with its final lyrics. It extends `music-video-hud` with a second influencer and character sheet, while keeping one mixed performance prompt list and one mixed performance audio list.

1. Call `list_templates` and `create_from_template`. Upload the song to n1.asset; supply the final lyrics at n3.lyrics. Set n34.influencer to the guest ID returned by `list_influencers` / `get_influencer`, or fill n4.guest with identity text in the same form as n4.figure (`NAME:`, `FULL:`, optional `SHORT:` and `CREDIT:`). An unselected influencer leaves the identity to the field.
2. Keep lead lines outside parentheses. Put each guest answer on its own whole line in round brackets, for example `(Not yet!)` or `(No.)`; [Choir] or a `Choir:` line prefix also marks the guest. Timing voice `choir` (including detected backing voices) is assigned to the guest only when a guest identity is given. The all-parentheses section exception still applies: read `get_guide` topic hud-music-video. Use [Choir] for a guest-only section.
3. n4.guest_sheet_prompt feeds the separate guest sheet n35, with n4.guest_sheet_refs as references. n34.images feeds n4.guest_image: up to six workflow PNG/JPEG/WebP images are accepted, the first three are used. The two image.generate sheets use the same image-model selector and 3:4 aspect. The guest sheet is the SECOND reference after the lead sheet on n9, n10 and n11; connection order matters. The text templates instruct the image model to draw only the named people, keeping each identity from its own sheet.
4. Short guest answers get their own performance units (down to about 1.2 s). Their audio starts exactly at the scene start and runs for at least 5.05 s for lip sync; silence pads the end of the song if necessary. The cut uses only the planned scene from the clip start at normal speed. Lead and guest remain in unit order in the same performance lists and use the same lip-sync node n12.
5. Review the brief, board, BOTH sheets and scene pictures with `get_workflow_results` before approving clips and HUD. Identity-preservation instructions still need visual review. Use `estimate_run`, agree costs, then `run_workflow`.

The guest identity is optional on music_video.hud_plan: without one its prompts, grid and output fields stay as before, and choir lines remain story clips. The duet template itself needs a guest identity because n35 has a required prompt input; without one it cannot finish. Use the original `music-video-hud` template for a solo film.

To retrofit another HUD workflow, first read `get_workflow` with include_graph and `list_node_types`. Keep n33, n4.figure, n5 and n12. Connect a second input.influencer's figure to n4.guest and images to n4.guest_image; wire guest_sheet_prompt / guest_sheet_refs to a second sheet. Add that sheet after n5 on each picture node's images input and adapt n6/n7/n8 to identify both references. No second performance list or lip-sync node is needed.
