# Montserrat (variable font, the weights 600, 800 and 900 are used)

- Used for: the Kuble style of the music video HUD (`lib/music-video-hud/`): the big words, numbers and titles (ExtraBold 800 and Black 900) and the karaoke line and the speech bubbles (SemiBold 600). One file holds every weight; the page asks for the weight with `font-weight`.
- Source: https://github.com/google/fonts, folder `ofl/montserrat` (file `Montserrat[wght].ttf`, the variable font with the axis `wght` 100 to 900, font version 9.000, last changed upstream in commit `76fca9fd0bb4ea46583f92e978660f3984ab9442`; checked against `main` on 2026-10-09). Upstream project: https://github.com/JulietaUla/Montserrat (the folder was built from its commit `cc8daf2e7085006b9c112542fc82b58afc13521d`).
- Licence: SIL Open Font License 1.1 (`OFL.txt`, copied from the same upstream folder). The copyright line names no Reserved Font Name.
- Change: the file is a subset (same character set as `lib/fonts/anton`). The axis tables (`fvar`, `avar`, `HVAR`, `MVAR`) are kept, `gvar` keeps the changes of the kept glyphs only, so every weight from 100 to 900 still works. The layout tables are removed: the kerning table alone is 300 KB, and the substitution tables could point at glyphs that are gone. The big words are set in capitals with a tight spacing, and the digits are set in cells of one width (`lib/music-video-hud/view.js`), so neither is missed. Made with `node scripts/subset-font.js "Montserrat[wght].ttf" lib/fonts/montserrat/Montserrat-Variable.ttf --keep-variations`. Only done to keep the embedded font small: the render node takes at most 2 MB of HTML per chunk (this file is 100 KB, 134 KB as base64).
- The widths of the text for the layout (`lib/music-video-hud/metrics.js`) are read from this file at the weight of the face (`HVAR`); they were checked against the widths that Chrome measures.
